# DEGSON 产品图片上传与预览

Directus 11 interface extension for `product_media.file_id`.

Provides a Chinese SKU image editor with upload, large preview, replace, clear, filename, dimensions, and file size. The extension only writes the existing Directus file ID value and does not change the product media data model.

Build with:

```text
pnpm install
pnpm build
```

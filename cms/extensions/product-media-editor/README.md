# DEGSON 产品图片上传与预览

Directus 11 bundle：编辑页 `product-media-editor` + 列表缩略图 `product-media-thumbnail`。兼容文件 UUID、站点 public 路径和外链。

Provides a Chinese SKU image editor with local upload, media library pick, large preview, replace, clear, filename, dimensions, and file size. The extension only writes the existing Directus file ID value and does not change the product media data model.

Build with:

```text
pnpm install
pnpm build
```

# Directus 后台运营体验

## 核心原则

后台是给运营人员使用的，不是给开发人员填数据库的。任何字段都必须先回答：运营人员看到这个字段时，能不能不读源码、不记内部值就完成正确操作？

禁止把数据库内部值直接暴露给运营人员作为普通文本输入，尤其是：

- 枚举值：使用下拉选择，不使用普通 input（仓库硬约定见根目录 `AGENTS.md`）
- 布尔值：使用开关或复选框，不使用 `true/false` 文本
- 状态：使用明确的中文状态控件，并限制可选状态
- 文件：使用上传/预览/替换/清除控件，不要求填写文件 ID 或 UUID
- 关联：使用关联选择器，并显示业务名称，不显示内部 ID
- 排序：使用数字控件，并用“显示顺序”等业务标签

## 开发前检查

涉及后台功能时，先检查：

1. 旧后台或需求文档中的真实运营操作流程。
2. 字段的业务含义、允许值、默认值、是否必填、是否可编辑。
3. Directus 当前字段的 `type`、`interface`、`display`、`options`、`hidden`、`translations` 和 `note`。
4. 当前页面是否有现成的可复用控件或自定义扩展。
5. 是否需要在列表页、编辑页、关联弹窗和文件预览中分别验收。列表页必须检查：列头是否中文、图片列是否缩略图而不是 URL。

不要只验证 API 能存储数据；后台操作路径本身也是交付内容。

## 控件映射规则

| 业务类型 | 默认控件 | 验收要求 |
|---|---|---|
| 有限枚举 | `select-dropdown` | 只显示中文业务选项，不能自由输入内部 code |
| 是/否 | `boolean` | 默认值明确，标签表达业务含义 |
| 文件/图片 | 自定义预览控件或可接受的文件控件 | 上传、预览、替换、清除；显示文件名/尺寸；不让用户处理 UUID |
| 一对多关联 | `list-o2m` | 子项字段顺序合理，父级上下文明确，普通字段不暴露内部 ID |
| 多对一关联 | `select-dropdown-m2o` 或等价选择器 | 显示名称/订货号等业务标识，而不是数字 ID |
| 数字排序 | 数字 stepper/input | 使用“显示顺序”等中文标签，提供合理默认值 |
| 长文本/富文本 | 对应文本编辑器 | 明确是否支持 HTML，前台必须经过安全清洗 |

## 图片字段硬规则

产品、新闻、分类或媒体相关的图片编辑不能只提供一个文件 ID 字段。至少要满足：

- 空值状态明确提示“还没有图片”；
- 有值时显示实际图片预览；
- 支持上传、从媒体库选择、放大预览、替换、清除；
- 显示文件名、尺寸或大小等可识别信息；
- 多图场景提供用途、排序和主图选择；
- 主图/详情图/工程图等用途必须是下拉选项；
- 没有真实图片数据时也要验收空状态，不能把空白输入框当作完成。
- 列表页图片列使用 `product-media-thumbnail`（或等价缩略图 display），不能把路径、UUID 或 URL 当单元格文本。

## 实施流程

1. 先写失败验证：验证控件类型、中文翻译、选项集合、隐藏字段和必填边界。
2. 再实现 schema 或后台界面，不要先改前台掩盖后台问题。
3. 运行幂等建模和元数据脚本。
4. 用真实编辑页完成一条操作路径：打开已有内容 → 新建/编辑子项 → 选择枚举 → 上传或选择文件 → 预览 → 清除/替换 → 保存。
5. 做一次视觉检查：不允许英文内部字段名、列表列头露出 `sort`/`image`/`hero_title`、UUID 代替业务名称、图片列显示 URL、空白控件没有说明、枚举仍可自由输入。
6. 最后跑 schema、后台元数据、TypeScript、前台回归和扩展校验。

## 本项目反例与正确做法

错误：`product_media.kind` 使用普通 input，让运营人员填写 `product_main`、`product_detail`。

正确：使用 `select-dropdown`，展示“主图 / 详情图 / 工程图”，保存时再映射为内部值。

错误：只在 `product_media.file_id` 上配置原生文件字段，页面显示小缩略图和 UUID。

正确：使用“产品图片上传与预览”界面，提供大图预览、本地上传、从媒体库选择、替换、清除、文件信息，并隐藏普通运营不需要的文件 UUID。

## 完成前检查清单

- [ ] 运营人员不需要知道数据库字段名或内部枚举值
- [ ] 没有把有限枚举做成普通文本 input
- [ ] 所有新增字段都有中文名称和操作提示；列表列头与编辑页标签均为中文
- [ ] 文件字段可预览、本地上传、从媒体库选择、替换、清除，空状态有说明；列表中显示缩略图而不是 URL
- [ ] 关联字段显示业务名称，不要求填写 ID
- [ ] 已在真实 Directus 编辑页操作过，而不是只调用 API
- [ ] 已对照旧后台或需求确认操作能力没有倒退
- [ ] 已运行对应 schema、元数据和前台回归验证

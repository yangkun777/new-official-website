## 3. 重要结论

1. 当前快照不是多语言全量快照，`language` 只有 `en`；不能据此判断其他语言内容已经可迁移。
2. 13,101 个产品候选中，重复订货号只有 3 组，但系列码重复有 184 组，系列归并是迁移的主要风险之一。
3. 旧库中的 `hr_article.classify` 在系列记录中承担分类 ID 角色；系列名称来自 `title`，不能把 `classify` 当成名称。
4. 旧库产品的 `text` 是订货号，`text1` 是间距，`text2` 是极数；这组语义已进入迁移契约，但仍需用全量数据抽样复核。
5. 产品媒体不能只看 `thumb`，还必须合并检查 `thumb1`–`thumb7`、`media`、`file` 和 `more_img` 等字段。

## 4. 当前不自动处理的事项

- 重复 SKU 和重复系列码的最终保留规则。
- 旧库多个 `description*`、`content*`、`text*` 字段的业务语义。
- 多语言字段与独立语言站之间的准确对应关系。
- 图片、PDF、媒体和历史 URL 的完整映射。
- 会员、表单、下载权限和私有数据迁移。

## 6. 复跑方式

建议通过环境变量传入只读连接信息，不把密码写入脚本：

```powershell
$env:MYSQL_PWD = "本机只读密码"
node data/migration/profileLegacy.mjs data/migration/reports/legacy-profile.json
```

JSON 明细报告默认输出到 `data/migration/reports/`，该目录只作为本地生成物，不应提交生产数据或凭据。

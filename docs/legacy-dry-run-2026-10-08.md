## 结论与下一步

当前不应直接做正式导入，也不应为了让数量变成 `READY` 而关闭分类外键校验。按照 PRD 的迁移门禁，下一步应先补齐：

1. `classify` 对应的旧产品分类来源，或一份经过确认的 `classify -> 新分类` 映射表。
2. 重复 `matecode` 的裁决规则，明确系列级和 SKU 级的唯一身份。
3. 重复订货号的 URL 归并方案；未裁决前不自动发布 301。
4. 重新执行 dry-run，目标是分类、系列、SKU 的 `READY` 数量可解释，且 `REVIEW/REJECT` 均有负责人和裁决记录。
